# Public result artifacts

Only compact, reportable metrics are included. Row-level predictions, JSONL logs, support examples, threshold-search traces, and local run paths are intentionally excluded.

- `ml/baseline_all_models.csv`: conventional ML results.
- `icl/benchmark_results_public.csv`: curated zero/few-shot progress table. Pending rows have blank metrics.
- `transfer_baselines/benchmark_results_public.csv`: HBM-CoPB and HBM-PB&J results plus the PB&J 17B placeholder.
- `flare_vax/reported_metrics.csv`: V4/V5 FLARE-VAX main runs and HBM8 pattern-only ablations. Historical 8-shot rows are excluded because the unified ICL table supersedes them.
- `all_results_public.csv`: one normalized long table generated by `scripts/90_collect_results.py`.
- `reward_memory/benchmark_results_public.csv`: full RG-FLARE-VAX stage-level metrics, including pattern anchor, reward prior, final reward-valued memory, no-memory comparison, and survey-weighted rows.
- `trbm/full_results_public.csv`: full TRBM-FLARE-VAX metrics, including unweighted and survey-weighted rows and the calibration-selected correction scale.
